# 🎲 Yatzy Online

A browser Yatzy game you can play with friends, each on their own laptop or phone. You can also play on one shared screen. No installs and no accounts needed.

**Play online:** https://zakir987.github.io/yatzy/

## Play with friends

1. Type your name and click **Create a game room**.
2. Send the **invite link** (or the 6-letter room code) to your friends, up to 6 players.
3. Choose the **Game rules**, wait for everyone to join, then click **Start game**.

The host's browser runs the game, so the host needs to keep their tab open. If a friend's connection drops, they can reopen the link and rejoin with the same name.

## How to play

- Roll up to 3 times per turn (you can change this). Tap dice to **hold** them between rolls.
- Pick an empty box on the scorecard (you can score 0). After 15 rounds, the highest total wins.

## Customisable rules

The host (or the local player) can change these:

| Setting | Default |
|---|---|
| Rolls per turn | 3 (from 1 to 5) |
| Upper bonus | 50 points for 63 or more in Ones–Sixes (both numbers can be changed) |
| Small Straight | **Any 4 in a row** (1-2-3-4, 2-3-4-5, 3-4-5-6) = 15, or only 1-2-3-4-5 |
| Large Straight | **Any 5 in a row** (1-2-3-4-5 or 2-3-4-5-6) = 20, or only 2-3-4-5-6 |
| Full House | Sum of all dice, or a fixed number of points |
| Yatzy | 50 |
| Extra Yatzy bonus | Off (you can set points for each Yatzy after the first) |

One-click presets: **Flexible**, **Classic Yatzy**, **Yahtzee style**.

Each player can also choose their own **dice colour**. It only changes their own screen.
